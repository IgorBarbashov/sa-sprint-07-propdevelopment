**Характеристика системы и инфраструктуры:**
- PropDevelopment - крупная строительная компания с несколькими доменами и комплексом IT-продуктов, включая онлайн-витрину, онлайн-тур, онлайн-сделку, мобильное приложение для собственников
- Инфраструктура гибридная: собственные серверы, приватное облако, ЦОД, аренда облачных мощностей
- Используется Active Directory для управления учётными записями
- Доступ внешних пользователей осуществляется через firewall
- Базы данных имеют резервное копирование
- Команды разработки и эксплуатации разделены, есть один специалист по ИБ, есть проблемы коммуникации
- Есть проблемы с контролем данных, API партнёров, отсутствием системного контроля доступа и безопасности данных

**Выбор разделов проверочного листа**
- **Управление доступом** - критично, т.к. есть проблемы с контролем учётных записей, доступом к данным, внешним API, используется AD, важно проверить MFA, принципы минимальных привилегий, аудит учётных записей, централизованный контроль и журналирование
- **Безопасность данных** - важный аспект, учитывая жалобы клиентов на ошибки в личных кабинетах, отсутствие системного контроля потоков данных, необходимость соответствия законодательству, резервное копирование, шифрование и классификация данных
- **Защита инфраструктуры** - необходима проверка firewall, сетевой сегментации, IDS/IPS, мониторинга, антивирусов, сканирования уязвимостей, контроля периметра, так как инфраструктура гибридная и критична для безопасности
- **Управление инцидентами** - учитывая обеспокоенность руководства после инцидентов у конкурентов, важно проверить наличие SIEM, процессов реагирования и анализа инцидентов
- **Специфические аспекты** - важны для комплексного аудита, особенно с учётом ЦОДа и арендуемых мощностей
